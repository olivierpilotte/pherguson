# Documentation Organization

## Overview

All documentation has been organized into the `docs/` directory to keep the project root clean and provide a centralized location for all project documentation.

## Directory Structure

```
docs/
├── README.md                    # Main documentation index
├── README_REFACTORED.md         # Refactored project guide
├── REFACTORING_SUMMARY.md       # Refactoring work summary
├── VIDEO_CRASH_FIX.md          # Video playback crash fixes
├── CONFIG_ACCESS_FIXES.md      # Configuration access issues
├── SOUND_AUTO_STOP_FEATURE.md  # Sound auto-stop feature
├── test_sound_monitoring.py    # Sound monitoring test script
└── DOCUMENTATION_ORGANIZATION.md # This file
```
